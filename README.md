# airline-passenger-satisfaction-analysis
End-to-end airline passenger satisfaction analysis using Excel, SQL, and Power BI.
This project analyzes airline passenger satisfaction using Excel, SQL, and Power BI.

The dataset contains 25,976 passenger records and includes passenger demographics, travel details, flight delays, service ratings, and overall satisfaction.

The main objective is to understand:

Who the passengers are
How satisfaction varies across different passenger segments
How satisfaction differs by travel type and class
How flight distance and delays relate to satisfaction
Which service attributes are associated with passenger satisfaction
Tools Used
Microsoft Excel – PivotTables and comparative analysis
SQL – Data analysis, aggregation, segmentation, and percentage calculations
Power BI – Interactive dashboard and visual analysis
Dataset

The dataset contains information about:

Gender
Age
Type of Travel
Class
Flight Distance
Departure Delay
Arrival Delay
Passenger service ratings
Overall Satisfaction

Each row represents one passenger.

Excel Analysis

Excel was used to explore passenger satisfaction through PivotTables and comparative analysis.

The analysis focused on:

Satisfaction by passenger segments
Satisfaction by class
Satisfaction by travel type
Age-group comparisons
Service-rating comparisons
Flight delay patterns
SQL Analysis

SQL was used to perform structured analysis of the passenger dataset.

Queries included:

Total passenger count
Satisfied and dissatisfied passenger counts
Satisfaction percentages
Satisfaction by class
Satisfaction by type of travel
Satisfaction by age group
Dissatisfaction by flight-distance category
Average departure and arrival delays by satisfaction

SQL techniques used include:

COUNT
AVG
SUM
ROUND
GROUP BY
ORDER BY
CASE
Subqueries
Window functions
Power BI Dashboard

The Power BI report contains two main pages.

1. Overview

The Overview page provides a summary of passenger satisfaction through:

KPI cards
Satisfaction breakdown
Satisfaction by flight distance
Satisfaction by age group
Satisfaction by gender
Satisfaction by type of travel
Satisfaction by class

2. Key Drivers

The Key Drivers page explores factors associated with passenger satisfaction.

It includes:

Key Influencers analysis
Decomposition Tree
Average departure delay
Average arrival delay
Analysis of service ratings
Passenger segmentation by class, travel type, satisfaction, and age group
Key Analysis Areas

The project examines relationships between satisfaction and:

Passenger demographics

Travel class
Flight distance
Service quality ratings

Arrival delays
